# css-without-js
ثلاث تأثيرات باستخدام HTML وCSS فقط: حركة مرتبطة بالسكرول، قيم عشوائية، وظهور العناصر بالتتابع  بدون JavaScript
# تأثيرات CSS بدون JavaScript

أكواد الأمثلة اللي شرحتها بالريل، باستخدام HTML وCSS فقط.

## الأمثلة

- Scroll-driven animation: صورة سفر بتكبر وبتعتدل مع السكرول، وبيظهر اسم المكان عليها.
- random(): ميلان الصور وتأخير ظهورها بقيم عشوائية.
- sibling-index(): ظهور الأغاني بالتتابع حسب ترتيبها، بدون تحديد تأخير لكل أغنية لحالها.

## التشغيل

نزّل الملفات وافتح ملف HTML الخاص بكل مثال بالمتصفح.
ما بتحتاج تثبّت أي مكتبات أو أدوات.

## دعم المتصفحات

بعض الميزات ما بتشتغل بكل المتصفحات. إذا مثال ما اشتغل عندك، تأكد من دعم الميزة بمتصفحك.
