# تأثيرات CSS بدون JavaScript

أكواد الأمثلة اللي شرحتها بالريل: ثلاثة تأثيرات باستخدام HTML وCSS فقط، بدون مكتبات أو JavaScript.

## المعاينة

[جرّب الأمثلة مباشرة](https://devtaimjaber.github.io/css-without-js/)

## الأمثلة

### حركة مرتبطة بالسكرول

صورة سفر بتكبر وبتعتدل مع السكرول، وبيظهر اسم المكان عليها باستخدام `animation-timeline: scroll()`.

### قيم عشوائية

ميلان الصور وتأخير ظهورها بقيم عشوائية باستخدام `random()`.

### ظهور العناصر بالتتابع

الأغاني بتظهر وحدة ورا التانية حسب ترتيبها باستخدام `sibling-index()`، بدون تحديد تأخير لكل أغنية لحالها.

## التشغيل محلياً

1. نزّل المشروع من `Code → Download ZIP`.
2. فكّ ضغط الملف.
3. افتح ملف HTML الخاص بالمثال بمتصفحك.

ما بتحتاج تثبّت أي مكتبات أو أدوات.

## دعم المتصفحات

بعض الميزات تحتاج متصفحاً حديثاً، وقد لا تعمل في جميع المتصفحات. تأكد من دعمها قبل استخدامها بمشروعك.
